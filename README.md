# Photo Culler

אפליקציה מקומית למיון תמונות (photo culling): סורקת תיקיית תמונות, מזהה תמונות מטושטשות/חשופות
לא נכון, מאתרת כפילויות (בורסטים/תמונות דומות), ומדרגת כל תמונה באמצעות מודל Vision מקומי דרך
[Ollama](https://ollama.com) — הכול רץ על המחשב שלך, בלי לשלוח תמונות לענן.

## איך זה עובד

1. **סריקה** — מעבר רקורסיבי על התיקייה, קריאת מטא-דאטה (EXIF).
2. **בדיקות טכניות מקומיות** (`backend/quality.py`) — חדות (Laplacian variance), חשיפה
   (היסטוגרמת בהירות + clipping), ו-perceptual hash לכל תמונה.
3. **זיהוי כפילויות** (`backend/dedupe.py`) — קיבוץ תמונות עם hamming distance קטן בין ה-phash
   שלהן (union-find), ובחירת התמונה הטובה ביותר מכל קבוצה.
4. **הערכת AI** (`backend/vision.py`) — כל תמונה נשלחת למודל Vision מקומי דרך Ollama עם פרומפט
   שמחזיר JSON מובנה (חדות, קומפוזיציה, עיניים פקוחות, ביטוי, ציון כולל, נימוק).
5. **ציון משוקלל** (`backend/pipeline.py`) — שילוב של ציון ה-AI (60%), חדות (25%) וחשיפה (15%)
   לציון סופי 0-100. אם Ollama לא זמין, הציון מתבסס רק על הבדיקות הטכניות.
6. **ממשק דפדפן** — גריד של תמונות עם הציונים, סימונים (מטושטש/כפילות), וכפתורי
   שמור/דחה/אוטומטי לכל תמונה. פעולת "החל" מעבירה (לא מוחקת!) את התמונות הנדחות לתיקיית
   `_rejected` בתוך התיקייה המקורית.

## דרישות מוקדמות

1. **Python 3.11+**
2. **[Ollama](https://ollama.com)** מותקן ורץ מקומית (`ollama serve`, או שהוא כבר רץ כשירות).
3. מודל Vision מותקן ב-Ollama. מומלץ:
   ```bash
   ollama pull gemma3:4b        # קל ומהיר, ברירת מחדל
   # או, לאיכות גבוהה יותר (דורש יותר זיכרון):
   ollama pull gemma3:12b
   # חלופות: llava, qwen2.5vl
   ```
   > הערה: נכון לכתיבת מסמך זה אין מודל בשם "gemma4" — `gemma3` היא המשפחה העדכנית של Gemma
   > עם תמיכה ב-vision דרך Ollama. אפשר לשנות את המודל בממשק (רשימת המודלים המותקנים נטענת
   > אוטומטית) או דרך משתנה הסביבה `OLLAMA_VISION_MODEL`.

## התקנה והרצה

### אופציה 1: סקריפט התקנה אוטומטי (מומלץ)

```bash
./setup.sh
```

הסקריפט יוצר virtualenv, מתקין את תלויות ה-Python, מתקין את Ollama אם הוא לא קיים (Linux/macOS),
מוודא ששרת Ollama רץ, ומושך את מודל ברירת המחדל (`gemma3:4b`). ניתן להריץ אותו שוב בבטחה בכל
שלב — כל שלב בודק אם הוא כבר בוצע.

אפשרויות:
```bash
./setup.sh --model gemma3:12b   # למשוך מודל אחר במקום ברירת המחדל
./setup.sh --skip-ollama        # להתקין רק את סביבת ה-Python, בלי Ollama
```

### אופציה 2: התקנה ידנית

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

ollama pull gemma3:4b     # ראו "דרישות מוקדמות" למעלה
```

### הרצה

```bash
source .venv/bin/activate
python run.py            # מאזין על http://127.0.0.1:8000
```

פתחו את `http://127.0.0.1:8000` בדפדפן, הזינו נתיב מלא לתיקיית תמונות ולחצו "סרוק תיקייה".

### הגדרות (משתני סביבה, אופציונלי)

| משתנה | ברירת מחדל | הסבר |
|---|---|---|
| `OLLAMA_HOST` | `http://localhost:11434` | כתובת שרת Ollama |
| `OLLAMA_VISION_MODEL` | `gemma3:4b` | מודל ברירת המחדל להערכה |
| `PHOTO_CULLER_DATA` | `~/.photo_culler` | היכן נשמרים ה-DB (SQLite) והתמונות הממוזערות |

## מבנה הפרויקט

```
backend/
  main.py       FastAPI app + כל ה-REST endpoints, ומגיש את ה-frontend הסטטי
  pipeline.py   מתזמר הסריקה: metadata -> quality -> dedupe -> AI scoring -> ציון סופי
  scanner.py    מעבר על התיקייה + קריאת EXIF/תמונות
  quality.py    חדות, חשיפה, perceptual hash (ללא AI)
  dedupe.py     קיבוץ כפילויות (union-find על hamming distance)
  vision.py     קריאה למודל Ollama Vision ופענוח תשובת JSON
  db.py         סכימת SQLite (טבלאות photos, scans)
  config.py     קבועים וברירות מחדל (משקלים, ספים, נתיבים)
frontend/
  index.html, app.js, style.css   ממשק דפדפן וניל-JS (RTL, ללא build step)
run.py          נקודת כניסה: מריץ uvicorn
```

הנתונים (SQLite + thumbnails) נשמרים תחת `~/.photo_culler` ולא בתוך תיקיית התמונות עצמה, כך
שאפשר לסרוק את אותה תיקייה שוב ושוב בלי לעבד מחדש קבצים שלא השתנו (בדיקה לפי mtime+size).

## הערות

- שום תמונה לא נמחקת אוטומטית. "החל" מעביר תמונות שסומנו לדחייה (או שהוצעו אוטומטית) לתיקיית
  `_rejected` בתוך אותה תיקייה, כדי שתמיד תהיה אפשרות לשחזר.
- אם Ollama לא זמין או שהמודל לא מותקן, האפליקציה ממשיכה לעבוד עם הבדיקות הטכניות בלבד (חדות
  וחשיפה), ומציגה זאת בממשק.
- מומלץ קודם להריץ על תיקייה קטנה כדי לבדוק שהמודל שנבחר עונה מהר מספיק — הערכת AI על הרבה
  תמונות יכולה לקחת זמן (תלוי בגודל המודל ובחומרה).
